# Проект #3. Массовый расчёт пространственного разрешения снимков (GSD)

**Сложность:** средняя (2/3).

## Проблема
У аэрофотосъёмочных заданий различаются высота и параметры камеры. Перед обработкой снимков нужно проверить, достигается ли требуемая детализация.

## Цель проекта
Создать программу расчёта **GSD (Ground Sample Distance, см/пиксель)** по списку заданий и сравнения его с допустимым порогом, не изменяя исходный файл.

## Исходные данные
`surveys.csv` – файл с заданиями. Путь к файлу задаётся при запуске.

Столбцы:
- `survey_id` – идентификатор
- `height_m` – высота над снимаемой поверхностью, м
- `focal_mm` – фокусное расстояние, мм
- `sensor_width_mm` – ширина матрицы, мм
- `image_width_px` – ширина снимка, пиксели
- `max_gsd_cm` – допустимый GSD, см/пиксель

Среди строк есть **числовые, но недопустимые значения**: нулевая фокусная длина, отрицательные высота, ширина матрицы и порог, дробная ширина изображения.
Модель учебная: надирная съёмка без учёта рельефа и наклона камеры.

`GSD_cm = height_m * sensor_width_mm / (focal_mm * image_width_px) * 100`

Задание соответствует порогу при `GSD_cm <= max_gsd_cm`. Сравнение выполняется по полному значению, без предварительного округления.

## Постановка задачи
1. Получить путь к файлу и прочитать строки CSV
1. Проверить параметры каждой строки; для допустимых вычислить GSD и сравнить его с порогом
1. Отделить корректные задания от строк с ошибками
1. Вывести сводку и сохранить отчёт рядом с консольным приложением, не меняя исходный файл

## Рекомендуемые средства Python
`csv`, `pathlib`, `math.isfinite`, функции, циклы, проверки диапазонов, `float`, `try/except`. Внешние библиотеки не нужны.

## Конечный продукт
- Скрипт `gsd.py` на Python с решением проектной задачи
- Файл `gsd_report.txt` с информацией: `survey_id`, GSD, соответствие порогу и диагностика ошибок

## Критерии приёмки
- [ ] Программа обрабатывает **все строки файла**
- [ ] Корректно считает GSD и соответствие порогу
- [ ] Корректная обработка типичных ошибок: несуществующий путь, путь к каталогу вместо файла, пустой файл, пустые поля, отсутствие столбцов, повтор `survey_id`, `NaN`/`inf`, нулевые или отрицательные высота, фокус, ширина матрицы и порог GSD, нецелая или неположительная ширина изображения
- [ ] Некорректная строка не приводит к завершению работы программы, а фиксируется в отчётном файле
- [ ] Исходный CSV не редактируется и не перезаписывается
- [ ] При повторном анализе одинаковых данных порядок, содержание отчёта и округление совпадают; сравнение с порогом выполняется без округления
