# Проект #5. Поиск пропусков фотографирования по географическим координатам

**Сложность:** повышенная (3/3).

## Проблема
При облёте промежутки между соседними точками съёмки могут оказаться слишком большими. Тогда снимки не перекрывают местность целиком.

## Цель проекта
Создать программу расчёта **расстояний в метрах между соседними точками** по широте и долготе и поиска интервалов больше заданного порога, не изменяя исходный файл.

## Исходные данные
`points.csv` – файл точек съёмки. Путь к файлу и порог расстояния в метрах задаются при запуске. Для этого учебного файла порог – **35 м**.

Столбцы:
- `point_id` – идентификатор
- `latitude_deg` – широта, градусы WGS84
- `longitude_deg` – долгота, градусы WGS84

Порядок строк – порядок съёмки. Считать нужно только **соседние** пары.

Расстояние считается по сфере, а не евклидовой формулой по градусам. Подходит формула гаверсинусов при радиусе Земли 6 371 000 м. Формулу студент выбирает и записывает сам. Интервал считается слишком большим при `расстояние > порог`.

## Постановка задачи
1. Получить путь к файлу и порог, прочитать точки в исходном порядке
1. Проверить идентификаторы и координаты; для соседних корректных точек вычислить расстояние в метрах
1. Отделить допустимые интервалы от слишком больших и от строк с ошибками
1. Построить и сохранить **график** зависимости расстояния до предыдущей точки от её порядкового номера: по горизонтали номер точки, по вертикали расстояние в метрах. У первой точки предыдущей нет, поэтому для неё значение не строится
1. Вывести сводку и сохранить отчёт рядом с консольным приложением, не меняя исходный файл

## Рекомендуемые средства Python
`csv`, `math` (`radians`, `sin`, `cos`, `asin`, `sqrt`), `pathlib`, `matplotlib`, функции, списки, циклы, `try/except`. Для графика нужна библиотека `matplotlib`. Пакеты `pandas` и `numpy` не нужны.

## Конечный продукт
- Скрипт `photo_gaps.py` на Python с решением проектной задачи
- Файл `gaps_report.txt` с информацией: пара идентификаторов, расстояние в метрах, превышение порога, число слишком больших интервалов и диагностика ошибок
- График `gaps.png`: расстояние до предыдущей точки по её порядковому номеру

## Критерии приёмки
- [ ] Программа обрабатывает **все строки файла** в исходном порядке
- [ ] Расстояния между соседними точками считаются в метрах
- [ ] Корректная обработка типичных ошибок: несуществующий путь, путь к каталогу вместо файла, пустой файл, пустые поля, отсутствие столбцов, повтор `point_id`, `NaN`/`inf`, широта вне −90…90, долгота вне −180…180, файл из 0 или 1 точки
- [ ] Некорректная строка не приводит к завершению работы программы и не связывает через себя несоседние точки; ошибка фиксируется в отчётном файле
- [ ] Сравнение с порогом строгое: расстояние больше порога отмечается, равное порогу – нет
- [ ] Исходный CSV не редактируется и не перезаписывается
- [ ] График подписан, сохранён и показывает расстояние до предыдущей точки по её номеру; первая точка на нём отсутствует
- [ ] При повторном анализе одинаковых данных и того же порога порядок, расстояния, флаги, округление и график совпадают
