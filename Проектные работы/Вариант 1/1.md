# Проект #1. Проверка папки аэрофотоснимков

**Сложность:** простая (1/3).

## Проблема
Перед фотограмметрической обработкой оператору нужно проверить содержимое папки с фотографиями: неверные имена, пропуски нумерации и нежелательные форматы затрудняют импорт снимков.

## Цель проекта
Создать анализатор **имён реально существующих файлов в выбранной папке**, не открывая и не изменяя сами фотографии.

## Исходные данные
`photo` – папка со снимками и тестовыми файлами. Путь к папке задаётся при запуске.
Шаблон корректного имени: `IMG_NNNN.jpg` (четыре цифры; расширение `.jpg` регистронезависимо). Нумерация может начинаться не с 0001; пропуски ищутся между минимальным и максимальным номером.
Анализировать только файлы непосредственно в выбранной папке, без вложенных каталогов. На одной файловой системе два файла с **полностью одинаковым именем** в одной папке существовать не могут; проверять следует **повтор номеров** (например, `IMG_0002.jpg` и `IMG_0002.JPG`, если файловая система это допускает), а не дубликаты изображений.

## Постановка задачи
1. Получить путь к папке и собрать имена находящихся в ней файлов
1. Выделить корректно названные снимки, файлы с некорректными именами/расширениями и повторяющиеся номера
1. Найти пропущенные номера в диапазоне корректной нумерации
1. Вывести сводку и сохранить отчёт рядом с консольным приложением, не меняя исходные файлы

## Рекомендуемые средства Python
`pathlib` (`Path.iterdir`, `is_file`), `re` или строковые методы, `collections.Counter` (необязательно), множества, циклы, функции, `try/except`. Внешние библиотеки не нужны.

## Конечный продукт
- Скрипт `photo_check.py` на Python с решением проектной задачи
- Файл `photo_report.txt` с информацией: по количеству файлов, корректных снимков, нарушений шаблона и повторов номера и списком отсутствующих номеров

## Критерии приёмки
- [ ] Программа анализирует **файлы из каталога**
- [ ] Корректно различает невалидные имена, пропущенные номера и повторяющиеся номера
- [ ] Корректная обработка типичных ошибок: пустая папка, несуществующий путь, путь к файлу вместо каталога
- [ ] Фотографии не переименовываются, не удаляются, не открываются для записи
- [ ] При повторном анализе одинакового набора файлов порядок и содержание отчёта совпадают (сортировка явно задана)
