# Проект #2. Пакетная оценка расхода заряда БПЛА по маршрутам

**Сложность:** простая (1/3).

## Проблема
Оператор сравнивает маршруты разной длины, скорости и энергозатратности. Нужно заранее оценить время полёта и остаток заряда с учётом обязательного резерва.

## Цель проекта
Создать программу пакетной обработки **нескольких CSV-файлов маршрутов** с расчётом расхода заряда по заданному показателю **%/км**, не изменяя исходные файлы.

## Исходные данные
`routes` – папка с тремя независимыми CSV-файлами: `urban.csv`, `park.csv`, `rural.csv`. Путь к папке задаётся при запуске.

Столбцы:
- `route_id` – идентификатор
- `distance_km` – полная длина маршрута с возвращением, км
- `speed_kmh` - средняя путевая скорость, км/ч
- `charge_pct` - заряд на старте, %
- `consumption_pct_per_km` – расход, %/км
- `reserve_pct` – обязательный остаток, %

Читать только файлы непосредственно в выбранной папке, без вложенных каталогов. Расход вдоль маршрута постоянный. Нулевое расстояние допустимо, скорость должна быть положительной. Модель учебная и не применяется для реальных решений.

Время (мин) = `distance_km / speed_kmh * 60`
Расход (%) = `distance_km * consumption_pct_per_km`
Остаток (%) = `charge_pct - расход`

Маршрут допустим при `остаток >= reserve_pct`.

## Постановка задачи
1. Получить путь к папке и прочитать находящиеся в ней CSV-файлы
1. Проверить структуру и числовые параметры; рассчитать время, расход и остаток заряда и определить допустимость по резерву
1. Отделить корректные маршруты от строк и файлов с ошибками
1. Вывести сводку и сохранить отчёт рядом с консольным приложением, не меняя исходные файлы

## Рекомендуемые средства Python
`csv`, `pathlib`, циклы, функции, `float`, условия, `try/except`, `math.isfinite` для отклонения `NaN` и бесконечности. Внешние библиотеки не нужны.

## Конечный продукт
- Скрипт `battery.py` на Python с решением проектной задачи
- Файл `battery_report.txt` с информацией: имя исходного файла, `route_id`, время, расход, остаток, допустимость и диагностика ошибок

## Критерии приёмки
- [ ] Программа обрабатывает **все CSV-файлы из каталога**
- [ ] Корректно считает время, расход, остаток и допустимость по резерву
- [ ] Корректная обработка типичных ошибок: пустая папка, несуществующий путь, путь к файлу вместо каталога, числа вне допустимых диапазонов, `NaN`/`inf`, отрицательная длина или расход, скорость <= 0, проценты заряда и резерва вне 0–100, повтор `route_id` внутри одного файла, отсутствие столбцов
- [ ] Некорректная строка не приводит к завершению работы программы, а останавливает обработку файла с выводом ошибки в отчетный файл
- [ ] Исходные CSV не редактируются и не перезаписываются
- [ ] При повторном анализе одинаковых данных порядок, содержание отчёта и округление совпадают
